什么是 this 指针？

简单来说，this 指针就是一个隐形的“自己”。

在 C++ 中，一个类（或结构体）可以实例化出成千上万个对象。为了节省内存，所有对象是共享同一份成员函数代码的。那么问题来了：当一个成员函数被调用时，它怎么知道是谁在调用它？

class Player {
public:
    int hp = 100;
    void takeDamage(int damage) {
        // 编译器实际上看它是这样的：this->hp -= damage;
        hp -= damage; 
    }
};

Player p1;
Player p2;

p1.takeDamage(20); // 怎么知道扣的是 p1 的血而不是 p2 的？

另一个理解：python 的类里面的函数传参、实例属性强制(显式)写self（不写self的属性是类属性，共用于一个类的所有实例，一个实例改了这个类属性，别的也会跟着改（你猜我怎么知道的）

当你调用 p1.takeDamage(20) 时，编译器在幕后偷偷做了一件事：它把 p1 的地址作为一个隐藏参数传给了函数。这个隐藏的参数，在函数内部就叫做 this 指针。(依据：___________)

  • 核心结论：this 是一个指向“当前调用该函数的对象”的指针。谁调用了这个函数，this 就指向谁。

如果你写 this.hp，编译器会非常死板地理解为：“你想找 this 这个指针变量内部自带的 hp 属性。”

但 this 只是一个普通的指针（类似一个 64 位的内存地址数字）(根本不是结构体），它内部根本没有一个叫 hp 的变量，于是编译器就会无情地报错：
